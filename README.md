# 📝 Lista de Tareas (Todo List)

Aplicación web para gestionar tareas desarrollada con HTML, CSS y JavaScript puro.

## 🚀 Funcionalidades
- Agregar tareas
- Marcar tareas como completadas
- Eliminar tareas
- Filtro por estado
- Contador de tareas pendientes
- Persistencia con localStorage

## 🧰 Tecnologías
- HTML5
- CSS3
- JavaScript (Vanilla)
- Git / GitHub

## 📌 Uso
1. Escribe una tarea
2. Presiona "Agregar"
3. Marca como completada o elimínala
